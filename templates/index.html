Num sistema pirata, ele pega os canais "roubados" e monta um arquivo pronto para o servidor distribuir. Aqui ele gera arquivos 100% simulados (não funcionam em painel real) só para demonstrar o fluxo.

🚨 O que são as Detecções: é o motor defensivo do laboratório. Enquanto a simulação roda, ele gera alertas (regras RULE-001 a RULE-008) para cada comportamento suspeito — token compartilhado, brute force, limite de telas, rotação de token etc. É exatamente o que o cliente precisa implementar para pegar o pirata no ato.
